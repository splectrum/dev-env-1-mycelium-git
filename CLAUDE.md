# CLAUDE.md — dev-env-1-mycelium

How to work in this repository, for AI use. `rules.md` holds the rules;
this repository is where they are first used and tested.

- **Collaborative:** discuss first, write what has settled. Natural
  language; KISS.
- **Proposals, not decisions:** the rules and the phase are proposals to
  be tested. When practice shows a rule is wrong, raise it.
- **The setup is designed as the work goes.**
- In a Claude Code cloud session, execution runs on the session's
  `claude/…` branch until the session is told to use `execute/main`.
