# Notes

The outcomes of the first development phase that aren't code or kept
runs: designs, decisions, vision and probes. The phase's request itself
is on `pending/default` (`pending/phase-1/request.md`).

| Note | What it holds |
|---|---|
| `status.md` | What the phase built, what it deliberately left out, and the P2P boundary question |
| `api.md` | The design as it was settled in discussion: the module APIs, the backend contract, instrumentation and units, test runs, requests as a repository's public API, self-contained repositories and cascading links, checkpoints and transactions |
| `vision.md` | Not settled, to explore for viability: bundles as transport, repositories linking repositories, the mycelium base layer, p2p-Kafka on Hypercore, P2P and the outside world, packages and deployments in P2P, the package repository and the seed node, operators |
| `next-phase-request.md` | A draft request for the second phase, with recommendations, for roadmap-1 |
| `probes/` | Throwaway scripts kept as the evidence behind the vision notes |
